# v0.2.15 触屏按钮布局

设置 → 触屏按钮布局 → 拖动编辑按钮位置。拖动技能、锁定、升降、辅助动作与换技能按钮，点“完成”返回设置。编辑时战斗冻结，拖动不会施放技能或启动长按连发。

当前位置自动保存在本浏览器。提供5个可命名方案，保存横屏、竖屏按钮位置与移动摇杆位置；选中方案后点“应用方案”切换，点“保存到此方案”覆盖该槽位。恢复默认会重置两个方向的按钮与摇杆，保留已有方案。浏览器禁止存储时明确提示无法持久保存。

布局按技能栏第1–5个位置保存，切换角色和技能页后复用。可选辅助按钮按战斗条件显示。本地双人的位置映射到各自半屏。位置会按当前按钮尺寸限制在可点击区域，避让其他按钮与训练面板；小屏底部保留现有角标空间。旧键位、血量、摇杆设置保持兼容。

## 验证

- Chrome、Microsoft Edge 的触屏模拟：320×568、390×844、568×320、844×390、768×1024，实际触摸拖动、方向独立保存、命名/保存/应用/恢复默认、刷新保留、编辑返回及双人边界检查通过。
- 22个角色、140个技能页/屏幕组合：默认布局与所有按钮集中到屏幕边缘的压力布局分别检查按钮中心/边缘命中、实际技能触发与遮挡，各140例通过。
- 9种手机和平板尺寸、900个菜单控件遮挡/滚动检查与65项按钮操作通过。
- 设置迁移、损坏数据、位置边界、方案深复制与存储异常检查通过。
- 仓库16组现有验证通过；生产构建与差异空白检查通过。

这些是桌面浏览器的触屏模拟检查，未使用物理 iPhone 或原生 iOS Edge/Safari 进行验收。布局和方案仅保存在当前浏览器，不会跨设备同步。
