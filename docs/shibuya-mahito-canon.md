# 涩谷：虎杖、东堂对真人

依据漫画第127–132话、动画第44–46集。官方集数介绍：[理非-参-](https://jujutsukaisen.jp/episodes/44.php)、[变身](https://jujutsukaisen.jp/episodes/45.php)、[变身-贰-](https://jujutsukaisen.jp/episodes/46.php)。对白以剧情摘要改写，不复制漫画台词长段。

两段都使用涩谷地面废墟：东堂登场起源于地下战场，此处开场对白交代登场与虎杖重振，直接进入共斗后的地面战。第二段增加冲击坑与碎裂地面。角色采用现有骨架的风格化模型：虎杖粉发、红兜帽制服，真人缝线脸与蓝灰长发，遍杀即灵体的硬化身躯和肘刃，东堂发髻与左手损伤。

## 原著事件与能力边界

- 虎杖能够攻击真人的灵魂；体内宿傩阻止真人随意使用无为转变改造虎杖。这不是让虎杖对一切伤害无敌。
- 涩谷虎杖只有体术、咒力与逕庭拳/黑闪表现；没有后期御厨子、赤血操术、反转术式、自身领域或飞行。
- 第一段真人耐久降到45%后可触发一次0.2秒自闭圆顿裹，东堂左手损伤、支援改为一次佯攻。战斗继续，玩家仍需击败真人；提前击败真人同样获胜。
- 第二段真人已经化为遍杀即灵体，不再给他普通形态的多重魂与可反复展开领域。硬化肉体减轻普通攻击伤害。
- 东堂的最终佯装拍手只制造误判，不能恢复不义游戏；一次使用，不交换任何角色位置。
- 原著最终战由虎杖黑闪收束；游戏挑战允许任意有效攻击击败真人，不要求指定终结招式。

## 游戏改编

耐久阈值45%、伤害、冷却、2秒黑闪输入窗口、可调用东堂换位的频率及场景比例属于游戏调校。原著中黑闪无法自由保证发动；按钮表示抓住逕庭拳延迟命中后的游戏机会，不能脱离窗口使用。逕庭拳有实际延迟第二击，远离目标会落空。2026-10-06 起移除剧情锁血和自动阶段胜利，普通攻击也可通关；黑闪保持为可选的高伤招式。

剧情固定操作虎杖，真人可在自由战斗中选择。自由战斗不执行断手、形态切换、剧情锁血等脚本；虎杖在自由战斗没有额外东堂支援。
