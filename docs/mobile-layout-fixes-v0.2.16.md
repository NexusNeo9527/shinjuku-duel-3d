# v0.2.16 移动端继续检查

## 问题与修复

1. 编辑中拖动按钮后旋转屏幕，拖动状态被直接清空，松手不再写入存储。统一结束拖动时保存变化、释放触摸捕获；同时覆盖失焦、页面离开、触摸取消和捕获丢失。一次拖动绑定开始时的横竖屏方向，避免跨方向写错布局。
2. 小屏横屏双人模式的部分随机布局中，先放下的按钮分割了剩余空间，后续按钮避让失败会退回已被占用的默认位置。现在按双方半屏独立计算完整布局；普通避让失败时重新排列整组按钮，不再逐个回退到占用位置。
3. 浏览器地址栏压缩可用高度后，568×280双人模式有按钮超出游戏区域。可用区域低于240px时压缩辅助按钮占宽和高度，保留技能按钮尺寸与底部角标空间。

- 旋转、失焦、丢失捕获、页面离开、触摸取消5个场景：拖动后内存布局与已存布局一致，松手后不丢失变化。
- 22角色、88组双人布局：随机位置与所有按钮集中在角落，含不同角色、技能页、恢复/复制/简易领域等条件按钮；边界、按钮中心及边缘命中、按钮交叉检查通过。
- 568×280、844×320较矮横屏共44组双人布局通过。
- 全部角色140组边缘压力布局：按钮命中、遮挡与实际技能触发检查通过。
- Chrome和Microsoft Edge触屏模拟的5种手机/平板尺寸：编辑、五方案保存/应用、刷新保留、恢复默认、横竖屏及双人边界通过。
- 原有65项按钮动作复查通过，包含菜单返回、设置、角色选择、练习与双人模式、全屏等操作。
- 原有16组验证通过。生产构建与差异空白检查通过。
