## 修复

- 弹体按轨迹检测接触，优先命中前方目标；快速交错攻击可相杀。对撞按接触时间排序，角色先挡住的弹体不会再参与后方对撞；纯视觉弹体不抵消真实攻击。
- 重合角色可稳定分离；AI 弹体防御加入反应延迟、来向和高度判断。
- P2 独立复制与目标锁定，键盘移动与自己的分屏相机一致。新增默认键为逗号（复制）和斜杠（锁定），旧键位配置迁移保留用户设置并避开冲突；启动时刷新 HUD 键位提示。
- 暂停、开局、进入训练时清空移动和疾跑输入；重建/移除触屏控制时停止连续施放。
- 开局重置黑闪、受击边框、木桩重生和旧事件；五条被动恢复计入无恢复挑战。
- 结算及重开清除仍存活的弹体，并释放网格、材质和拖尾资源。
- 本地战绩按原模式/自由模式和开局生命上限分档；灵魂伤害降低上限不另开记录；损坏存储可恢复，非法成绩不保存。
- 分屏 HUD 显示实际施法限制与复制术式；有限训练显示充能不足；新结算图片加载前隐藏旧图片。
- 修正训练面板在竖屏和低高度横屏中的可滚动区域；校正文档中与当前实现不符的难度、鹿紫云倒计时和虎杖有限恢复说明。
- 修复专项测试中未推进近战有效帧、未清除演出暂停、未完成审判就断言普通攻击等过时步骤。测试继续断言业务效果，没有删除失败检查。

## 设定证据与验收边界

原作规则与游戏数值改编分别记录在现有 canon 文档中。官方动画第 28 集简介支持甚尔与夏油交战的时序，第 45 集简介明确虎杖、真人、东堂均使用黑闪：[第 28 集](https://jujutsukaisen.jp/episodes/28.php)、[第 45 集](https://jujutsukaisen.jp/episodes/45.php)。这些资料不能证明所有漫画细节，未把数值改编当成原作事实。

脚本配对验证的是运行稳定性、有效交互与结算，不证明对战平衡。真机触控/全屏、长时间显存增长、实际听感及完整玩家体验仍需实机试玩。构建和回归通过也不代表线上版本已更新。
