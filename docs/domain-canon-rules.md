# 当前领域的原著规则与改编边界

本次覆盖游戏已有的五种领域。剧情仍以击败敌人为通关条件；判决、处刑剑和原著结局不作为额外通关门槛。四档难度继续改变敌人强度。

## 规则与画面

| 领域 | 当前实现 |
| --- | --- |
| 无量空处 | 信息灌输使目标持续不能移动、冲刺、体术或施法，不再在后半程自动恢复；不以普通持续扣血代替信息效果。施术者及接触施术者的人豁免。保留领域对抗成立前的即时反制窗口。内部使用信息流空间。 |
| 伏魔御厨子 | 开放领域留在现实空间，可以逃离斩击范围；有咒力目标用捌、零咒力目标用解。等强度领域重叠处必中抵消，外侧斩击能侵蚀封闭结界。神龛不是可攻击的领域核心。 |
| 自闭圆顿裹 | 完整领域的必中无为转变不需要手部接触，伤害并持续降低目标生命上限，普通反转治疗无法恢复这个上限。触及仍为宿傩容器的涩谷／死灭回游虎杖或宿傩的灵魂时，宿傩反击并使领域崩塌；新宿虎杖不再触发该反击。涩谷剧情保留0.2秒展开与既有剧情演出。内部为手掌围成的空间，镜头保持在手墙内。 |
| 真赝相爱 | 雅各布天梯作为选定的必中，暂时解除目标术式；其他已配置复制术式随机存于刀内，拔刀时才确定，使用后该刀消失，领域内不能手动切换预选。内部使用刀阵和结绳，天梯使用竖向光束表现。 |
| 诛伏赐死 | 审判阶段禁止暴力，按被告显示指控；只有日车看到检方证据。玩家被告可选择否认、自白、默秘。无罪不没收、不授剑；有罪先没收携带的咒具，再考虑生得术式，没有术式则没收咒力。只有死刑判决授予处刑人之剑，剑只处决该案被告且必须命中；日车倒下后剑消失。死刑时审判者睁眼、流下血泪。 |

同级封闭领域可以共存，重叠处必中互相抵消。完整简易领域、持续维持的彌虚葛籠抵消必中；它们不让目标免疫普通攻击。彌虚葛籠占用双手，四臂宿傩有额外双手可行动。领域必中不受普通冲刺无敌帧或普通防守减伤抵消。封闭领域不自动捕获零咒力目标。

## 日车按被告审判

| 被告 / 场合 | 案件和结果 |
| --- | --- |
| 死灭回游虎杖，第一次审判 | 未成年进入柏青哥店：有罪、没收咒力，不判死刑。 |
| 虎杖，涩谷案 / 剧情再审 | 证据指出宿傩控制身体杀人。否认或默秘得到无罪；自白对应原著的没收与死刑分支。 |
| 宿傩 | 涩谷大量杀人案：没收与死刑。完全受肉形态持有神武解，优先没收该咒具，保留解与捌。未持有神武解的形态没收术式。 |
| 真人、鹿紫云 | 配置了依据角色行为的自由对战推演，界面明确标注；原著未展示日车审判他们，咒灵是否受该领域审判也未获确认。 |
| 其他角色 | 当前没有配置足以成立的原著罪行证据，判无罪；不会把战斗或正当防卫自动算成犯罪。 |

这是有限、可核验的案件表，并非自动生成罪名的法律模拟。玩家被告有9秒阅读答辩，随后2.5秒结算；超时使用该剧情的默认答辩。通用战斗每场一次，虎杖剧情允许一次再审。无罪、撤剑也仍可通过击败对手获胜。

## 仍属游戏改编的部分

伤害、时长、范围、外壳耐久、术式熔断和敌人强度均为游戏参数，不声称数值等同原著。真人的灵魂改造使用伤害与永久生命上限损失表达，没有对所有角色强制一击死亡；无量空处未模拟离开后长期脑损伤。乙骨当前复制术式池只有已实现技能，刀阵消失与随机拔刀不包含完整拾取动画。日车尚未实现任意罪名、多证据辩论或对已有敌方领域的完整结界争夺；敌方领域存在时不能直接强制审判。零咒力角色自愿入域未实现。

这些限制不属于原著新增设定。新增领域机制的回归测试在 `tools/verify-story.mjs`，并同时检查开放领域、封闭领域、简易领域、领域对抗和特效的既有验证程序。
