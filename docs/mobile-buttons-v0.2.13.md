# v0.2.13 移动端按钮验收

## 修复

- 单人触控按钮采用横向升降行和紧凑辅助按钮，避免多技能页、复制、恢复、简易领域等额外按钮使整个按钮组越出屏幕。
- 竖屏练习面板根据实际按钮组高度限制位置与可滚动高度；矮横屏面板避开右侧按钮。
- 横屏提示移至竖屏底部留白，手机技能插画移出技能按钮区域。
- 窄屏双人模式限制双方按钮组宽度，避免互相遮挡，并将升降按钮横排。
- 退出原生或应用回退全屏时取消延迟回退，避免快速退出后再次进入全屏；回退全屏可直接退出。

## 本地验证（2026-10-09）

浏览器使用 Chrome 的触控模拟，验证真实 Pointer Events、触控命中与游戏状态变化。

- 9 种视口：320×568、360×640、390×844、424×673、568×320、667×375、844×390、932×430、768×1024。
- 主页、模式选择、说明、设置、角色选择、剧情、难度、暂停和结算页面共 846 次控件布局检查，检查滚动后的按钮中心与边角命中，未发现遮挡或越界。
- 5 种代表视口下完成 65 组功能验证：导航返回、音量和静音、角色选择、难度、剧情章节、暂停恢复和重开、结算再战和接续、练习开关和训练、冲刺、近战、锁定、复制、强行恢复、简易领域、升降按住及松开、音乐、全屏和提示关闭。
- 22 个角色在 4 种代表视口下共 140 组技能页布局，532 次技能触控均到达施法逻辑，其中 496 次成功释放，36 次被技能条件拒绝（如黑闪窗口、审判判决、电荷等）。未发现技能插画、练习面板或提示与按钮重叠。
- 验证实际换页、第二页技能释放、冷却及充能限制、摇杆与技能同时触控、长按松开后停止连发。
- 双人模式在 320×568、568×320、844×390 下，两侧按钮中心命中通过。
- 5 种视口下的 15 次审判答辩点击通过；摇杆位置可拖动并通过触屏按钮恢复默认。
- 原生全屏不支持、请求拒绝、请求无响应三种模拟环境下，应用全屏回退均可进入和退出。
- 浏览器未记录未捕获的脚本错误。
- `npm run verify:all` 的 16 个现有验证套件全部通过；`npm run build` 和 `git diff --check` 通过。

验证边界：未进行实体手机、iOS Safari 原生全屏或设备帧率验收。Git 推送与 GitHub Pages 部署分别核验。
