# 战斗玩法改善

## 2026-10-07：弹体、防守与练习入口复查

- 非贯穿弹体按轨迹上最早接触目标的顺序结算，避免实体列表顺序导致越过前方敌人；天逆鉾接触消除也参与这个顺序，不能隔着前方角色取消已经先命中的弹体。命中粒子和场景反馈使用实际接触点。
- 弹体相杀检查双方在本帧内的相对运动，避免高速迎面弹体在帧间交叉却互相穿过；不同高度仍可错开。
- 完全重叠的角色使用确定的水平方向分离，不再因为零距离无法产生分离方向。
- AI 单独记录首次发现来袭弹体的时间，并根据弹体方向侧向闪避；缺少施法者出招时间也能反应。预测包含高度与速度，远离、从头顶越过或仅供显示的弹体不会触发闪避。反应延迟沿用难度参数。
- 修复421–620px竖屏和短横屏展开练习面板超出战场的问题，面板限高并可滚动；触屏横屏另外为右侧技能区留出空间。
- 同步新宿设定文档中的幻兽琥珀90秒改编倒计时、虎杖有限反转术式，以及领域说明中的时期对应宿傩容器身份；README难度表与当前耐久、输出和无被动承伤减免的实现一致。

验证：新增回归覆盖正反实体顺序、天逆鉾遮挡顺序、高速交锋、高度错开、零距离角色分离、AI反应延迟和无威胁弹体。内置浏览器的独立战斗实例得到前方／后方目标生命90／100、交叉弹体归零、角色间距1.4米、AI延迟后反应；浏览器无脚本错误。424×673竖屏练习面板从超出战场102px改为完整位于战场内，实际滚动可访问三个训练任务；844×390横屏面板同样完整位于战场内。自动检查不代表全部角色组合的胜率平衡或真机触屏手感验收。

2026-10-07 设定修复：

- 涩谷与死灭回游虎杖仍是宿傩容器；新宿虎杖保留灵魂感知，但不再触发宿傩对真人领域的反击。三种虎杖有咒力时均可打击真人灵魂，咒力没收后仅剩肉体伤害。
- 真人普通拳击与遍杀即灵体的拳脚可随机触发黑闪；无为转变、肘刃、法槌和接触斩击不参与体术黑闪判定。随机概率和伤害倍率属于游戏改编。
- 近战接触、依赖生得术式、黑闪资格分别标记。御厨子接触斩、法槌、无为转变等在熔断期间不可发动，普通拳脚、防守、反转术式仍可使用；AI、键盘与触屏锁定同步。
- 幻兽琥珀每战只能不可逆发动一次，重复声波／电磁波不会续期。剧情雷神挑战从已发动状态开始，自由模式首次使用琥珀技能时发动。90秒后肉体崩解并退场；90秒为游戏改编，原著没有这个倒计时。胜利结算后不继续推进崩解，练习重新开始也会重置本场状态。
- 新宿虎杖增加反转术式，每战最多三次，每次恢复14、冷却16秒并消耗满蓄力；这些数值为游戏改编。低血量协战AI优先恢复，没有添加后期御厨子或领域。
- 移动端显示恢复剩余次数和幻兽琥珀不可逆倒计时；有限资源练习的蓄力锁定与引擎一致。

设定依据沿用前次审核的原著时期划分；真人黑闪参照动画官方第45集介绍，幻兽琥珀参照237–238话，新宿虎杖反转术式参照248话。场景模型与碰撞未修改。

验证：完整 `npm run verify:story`、`npm run build` 和 `git diff --check` 通过。新增回归包含三种虎杖对真人的灵魂伤害／领域反应、接触术式熔断、黑闪资格、恢复次数及协战AI恢复、幻兽琥珀首次发动／重复施法不续期／超时退场。Edge 844×390 移动视口实际点击恢复按钮，生命40→54、次数3→2；雷神挑战显示不可逆倒计时，无脚本错误。截图为 `art/canon-yuji-heal-mobile.png`、`art/canon-amber-mobile.png`。90秒压力和三次恢复的平衡尚需真人试玩；未提交或推送。

- 体术防守、涩谷虎杖防守、真人硬化防守减轻 50% 体术伤害；日车展延维持 60% 减伤。体术防守不能抵消术式和领域必中，彌虚葛籠仍使用原反领域规则。命中时显示格挡反馈。
- 通用近战改为轻击 0.12 秒前摇、0.20 秒收招，重击／黑闪 0.24 秒前摇、0.36 秒收招。命中时重新检查距离和攻击方向，可通过离开范围或绕向身后来躲避。受击会打断未完成的近战；冲刺可以取消近战，但不返还已消耗的冷却。下一招可在结束前 0.25 秒输入，只有实际开始才消耗冷却。借用五条身体关卡继续使用其专属施法、突进和打断流程。
- AI 直线追击遇到碰撞体时使用缓存的 2 米导航网格绕行，每 0.8 秒最多重规划一次；实体移动继续经过原碰撞处理。加入对蓄势、近战前摇和接近弹体的闪避／防守反应。新宿协战 AI 不再无条件排除防守，也不会满血随机用恢复。近战选招按三维距离检查。
- 自由单人和双人对战中，只要一方为地面角色，双方采用地面对战规则。升降输入与垂直冲刺均关闭，触屏隐藏升降按钮。剧情关卡与纯空中对战沿用原规则。
- 通用随机黑闪仅适用于标记为体术的攻击与普通攻击，远程术式不会因距离近而触发。涩谷虎杖保留逕庭拳延迟命中后的两秒黑闪机会。
- 练习面板新增格挡一次、闪避一次、逕庭拳接黑闪三项短训练。任务切换到涩谷虎杖和固定陪练、正常冷却与可受伤状态；前两项由陪练定期预告出拳，成功由真实伤害／闪避判定记录。失败后可点击任务重新开始。
- HUD 新增当前关键提示，优先显示处刑剑与蓄势威胁、黑闪机会、熔断和收招说明。原状态详情保留。
- 通用困难／地狱敌人血量 125/150 调到 115/130，输出倍数 1.25/1.5 调到 1.1/1.2，移除难度造成的被动受伤折扣。反应、瞄准、机动和魔虚罗难度差异保留。乙骨专属困难／地狱耐久调到 110/120，地狱输出调到 1.15；同样移除被动受伤折扣。
- 结算增加用时、造成伤害、承伤、有效攻击命中率。命中率按发起的攻击次数及至少命中一次的攻击次数计算，排除领域与召唤的独立攻击；同一束攻击多次命中只计一次。造成伤害包含己方召唤物，按实际扣除生命计算，避免处刑过量伤害夸大统计。
- 获胜记录保存本机最佳用时与胜利次数，按模式、关卡、角色组合、难度、玩家生命上限、空地规则和挑战种类分开。练习与双人模式不写入记录；存储不可用时不影响战斗。
- 难度页新增无恢复／承伤不超过 25 的可选挑战。它们仅增加结算评价，仍以击败对手为通关条件。

## 验证

### 再次回归检查

- “苍”仅在有效命中后施加牵引，无敌／闪避挡住伤害时也挡住位移；正常牵引保持原效果。
- 五条对宿傩的专属 AI 生命、伤害、冷却和出手节奏减益只用于原模式。自由对战不再受之前选择的角色影响，原模式的减益仍保留。
- 同一角色只能维持一个领域，重复施法不会消耗领域值或冷却，也不会叠加必中；领域结束后仍可按正常条件再次展开。玩家、AI、练习和内部展开入口采用一致限制。
- 缓冲输入遇到暂时不满足的释放条件时，在原有 0.25 秒窗口内重试；超过原期限后清除，不会提前丢弃或无限延长。

回归验证覆盖牵引命中／无敌、模式切换前后自由对战数值、原模式减益、四种领域在双人／练习模式中的重复展开，以及缓冲重试与过期。

### 攻击反馈与关联问题

- HUD 短暂显示命中、重击、黑闪、被格挡、挥空、被闪避和术式阻隔；双人模式标明 P1／P2，使用已有粒子、受击闪色和屏幕反馈，不新增场景网格。普通提示维持 0.65 秒，不遮挡输入。
- 挥拳只播放一次挥动音效，有效命中播放撞击音，格挡播放独立声音，挥空和闪避不播放命中声音。普通体术接触增加 0.025 秒停顿，重击 0.055 秒，黑闪保留原有 0.1 秒。停顿中的下一次施法／普攻可缓冲，恢复后执行；暂停期间不立即生成攻击或消耗冷却。
- 无敌陪练显示“命中 · 无敌”等文字，反馈不再虚报扣血。HUD 数字按实际扣除的生命计算。
- 修复弹体／光束在伤害判定失败后仍击退目标的问题；仅有效命中施加击退。无敌陪练不再累计开放领域维持伤害，领域状态仍能反馈有效接触。
- 重开时释放尚未消失的伤害数字材质和纹理，避免反复重开积累 GPU 资源。

新增模拟覆盖反馈类型、声音区分、击退有效性、无敌领域维持以及停顿输入缓冲。移动视口 Edge 实际显示了黑闪、重击、挥空、闪避和格挡，无脚本错误；截图见 `art/attack-feedback-mobile.png`。数值与触屏手感仍需真人试玩。

### 审判、领域和停顿边界修复

- 近战站位依据角色首个攻击的实际类型确定，自由对战的日车、东京第一结界虎杖和鹿紫云会接近有效攻击范围。15 个可选角色逐一担任 AI 的 30 秒模拟均能发起攻击并造成伤害。
- 进入审判取消近战、施法蓄势、缓冲输入、黑闪机会及在途弹体／光束／逕庭拳延迟段。判决后不能恢复判决前的攻击；移动和碰撞仍走原有规则。
- 没收咒力后，逕庭拳仅保留肉体首击，不再附加延迟咒力、硬直或黑闪机会；已排队的延迟段也会失效。
- 练习无敌保护统一用于直接扣血和真人领域的灵魂改造，保护玩家或木桩的生命及生命上限；关闭无敌后恢复原有灵魂改造效果。
- 命中停顿先于战斗计时执行，冻结战斗用时、审判、蓄势、延迟命中、冷却和黑闪窗口；演出计时继续，停顿结束后战斗恢复。
- 无量空处的信息命中清除未完成的近战和缓冲输入，与原有施法／突进中断一致。

新增检查覆盖审判前后的攻击、在途攻击取消、没收咒力后的体术边界、双方无敌开关、停顿中的三种战斗计时，以及无量空处的近战中断。

Edge 移动视口 844×390 的实际运行引擎验证了审判取消近战、判决后不恢复旧攻击，以及无敌木桩在真人领域中的生命／上限保持 100；未出现浏览器脚本错误。完整 `verify:story`、构建和差异检查通过，真机手感仍需试玩。

### 后续六项修复

- 同帧到达命中时点的近战统一结算，已到命中时点的攻击可以互相命中；仍在前摇中的攻击照常被受击打断。致命互击先处理双方倒地，再结算平局，结果不受实体排列顺序影响。
- 逕庭拳仅在首击有效命中时附加延迟段；延迟段保留原攻击编号，不会清除闪避无敌。只有延迟段有效命中才给予硬直和两秒黑闪机会。
- 近战优先攻击范围内锁定的敌人，包括魔虚罗和里香；没有有效近距离锁定时选择范围内最近敌人。东堂剧情支援仍不可受伤。
- 技能特写暂停期间禁止施法、普攻、冲刺、简易领域和强行恢复。暂停结束后恢复正常输入，不在暂停期间消耗冷却或生成攻击。
- 练习关闭无限术式后，不再自动补满能量，奥义／领域正常检查并消耗资源；开启时保留原来的无限资源与短冷却。
- 练习无敌只阻止生命扣除，不再吞掉有效命中、电荷、连招、黑闪与受击反馈。闪避无敌和术式阻隔仍可阻止命中；统计伤害依然按实际扣血计算。
