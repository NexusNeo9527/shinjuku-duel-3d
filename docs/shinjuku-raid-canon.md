# 新宿：鹿紫云挑战与日车、虎杖协战

剧情顺序：雷神挑战 → 日车与虎杖 → 乙骨本体 → 五条之身。均可从剧情菜单直接选择，击败对手即获胜，玩家倒下即失败，不强制复现原著败北。

## 原著依据

- 漫画237–238话：万留下的神武解由里梅送达；鹿紫云的电性质使雷击无效。幻兽琥珀重构肉体，使用声波、电磁波等电相关现象；宿傩完全受肉并以扩张对象的解迎战。本关从完全受肉之后开始。
- 漫画244–245话：日车以涩谷屠杀案再审，宿傩承认罪行；没收优先作用于咒具神武解，宿傩术式仍可用。死刑判决授予处刑人之剑。
- 漫画246–247话：日车领悟领域展延与反转术式，虎杖参与接续进攻；处刑人之剑只杀死被判死刑的目标，命中才生效。
- 漫画248话：神武解没有返回，乙骨接续参战。因此乙骨两关不装备神武解。

章节资料：[鹿紫云与宿傩](https://jujutsu-kaisen.fandom.com/wiki/Hajime_Kashimo_vs._Sukuna)、[幻兽琥珀](https://jujutsu-kaisen.fandom.com/wiki/Mythical_Beast_Amber)、[诛伏赐死](https://jujutsu-kaisen.fandom.com/wiki/Deadly_Sentencing)、[245话](https://jujutsu-kaisen.fandom.com/wiki/Chapter_245)、[248话](https://eiga-manga.com/entry/jujutsu248)。这些为章节索引与梗概，未宣称读取付费原作全文。

## 游戏改编

- 幻兽琥珀从剧情开战起已发动，不可解除或重复发动；自由模式首次使用琥珀技能时发动。90秒战斗时间后肉体崩解并退场，重复施法不会续期。90秒为游戏改编，原著没有这个明确时限；胜利结算后停止推进倒计时。技能伤害、冷却、三次近身命中蓄满电荷均为游戏数值。
- 日车由玩家控制，虎杖为可受伤、可退场的主动协战角色。虎杖使用灵魂边界拳击与248话对应的反转术式，不使用后期觉醒的御厨子、领域或涩谷的东堂支援。恢复每战最多三次，每次恢复14、冷却16秒、消耗满蓄力，均为游戏改编；低血量协战AI可主动恢复。协战角色倒下不强制判负。
- 本剧情对宿傩审判每场一次，依原著指控涩谷屠杀案；2.5秒期间禁止攻击、移动与冲刺，判决后优先没收神武解并授予处刑人之剑，不剥夺宿傩的解与捌。自由战斗现可选择日车，案件按实际敌人、答辩和证据变化，详见 [领域规则](domain-canon-rules.md)。
- 处刑人之剑准备0.65秒，近身且沿准备时的方向刺中被判决者才能处决；准备可被伤害打断、目标可闪避。普通法槌及体术也能击败宿傩，不要求使用审判或处刑剑。
- 宿傩的扩张对象斩击有1.15秒提示并固定方向；不给这个阶段添加伏魔御厨子、魔虚罗或火焰。一般斩击、领域展延减伤与四臂防守采用游戏数值。
- 简单、普通、困难、地狱沿用剧情难度配置，敌人耐久、伤害、移动、反应随档位增加；虎杖的伤害不随敌人难度增加。
- 新角色为游戏内程序化风格模型；法庭、鹿紫云战场、日车战场和死灭回游剧场已有独立Blender源场景和GLB资产，见 `art/canon-trial-arenas.md`。
