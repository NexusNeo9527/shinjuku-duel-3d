# 死灭回游：虎杖对日车

此关是漫画164–166话、东京第一结界的剧场单挑，与新宿「日车、虎杖对宿傩」为不同关卡。

原著依据：虎杖寻找拥有100分的日车，请他添加规则。第一次诛伏赐死审理未成年进入柏青哥店的行为；虎杖当时没有术式，没收作用于咒力，他依靠肉体抵挡可变形法槌。再审涉及涩谷屠杀案，虎杖认罪，日车获得处刑人之剑；日车认识到真正凶手是宿傩，撤回剑并给出100分。

章节资料：[虎杖对日车](https://jujutsu-kaisen.fandom.com/wiki/Yuji_Itadori_vs._Hiromi_Higuruma)、[164话](https://jujutsu-kaisen.fandom.com/wiki/Chapter_164)、[166话](https://jujutsu-kaisen.fandom.com/wiki/Chapter_166)。这些为章节资料，非直接读取付费原作全文。

实现：独立剧场，包含幕布、座椅、浴缸、舞台及中央战斗通道。初始第一审禁止暴力，之后没收咒力，以肉体连拳、重击、防守对抗法槌。此时期日车不携带新宿才领悟的领域展延或反转术式；虎杖不带御厨子、领域、灵魂边界拳击或东堂支援。

改编：再审为可选技能，按R要求一次再审；不要求再审即可击败日车。第二审后短暂获得处刑剑，日车随后撤回，不自动结算胜负。2.5秒审判、3秒撤剑、技能冷却与伤害为游戏调节值；避免原著中的和解成为强制通关流程。玩家实际击败日车才赢，玩家倒下则失败；四档难度增强敌人强度。

验证：`npm run verify:story` 检查第一审禁止暴力、咒力没收、时期技能、单挑无协战者、可选再审、撤剑不强制结束以及四档普通体术胜利。
