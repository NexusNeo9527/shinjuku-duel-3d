# 伏魔御厨子：原著机制与游戏实现

参考漫画第119话（开放式领域、逃路与最大200米范围）、第262话（缩小范围包围乙骨微型结界）及第225–230话（领域对抗、外侧破坏结界、宿傩受创后难以维持领域）。

- 官方章节索引：[119](https://www.viz.com/shonenjump/jujutsu-kaisen-chapter-119/chapter/21187)、[225](https://www.viz.com/shonenjump/jujutsu-kaisen-chapter-225/chapter/39143)。本次未通过网页读取付费漫画内页。
- 机制交叉核对：[Malevolent Shrine](https://jujutsu-kaisen.fandom.com/wiki/Malevolent_Shrine)，包含上述原著章节引用。

## 已实现

- 开放结界，领域在现实战场中展开；无球形外壳，不捕获、传送或限制移动，不附加领域减速。离开斩击范围即可避开后续领域伤害。
- 必中持续斩击，普通冲刺无敌帧不抵消必中；简易领域在完整时抵消必中，同时承受侵蚀。
- 有咒力目标使用捌的表现，无咒力的甚尔使用解的表现；开放式领域仍能伤害甚尔。
- 与等强度封闭领域共存，重叠处必中抵消。现实空间里的封闭结界外侧被斩击侵蚀，结界崩塌后封闭领域术式熔断，伏魔御厨子继续存在。
- 神龛不是可被光柱打掉的领域核心；宿傩累计受到足够伤害后无法维持领域并术式熔断。
- 既有剧情场景的可破坏物件收到范围斩击事件。

## 游戏改编边界

原著约200米为最大半径，并非每次固定采用。现实战场距离统一为1场景单位=1米；通常展开采用半径200，中心展开时覆盖当前144×144米的可移动区域和最高30米飞行高度。领域是以施术位置为中心的有限范围，不把地图边界作为必中边界：在地图角落展开时，超过200米的远端仍然可安全逃离。取消此前固定缩尺为40的规则。

第262话对应的借体剧情中，封闭领域的物理外壳半径使用0.12米近似篮球尺度（具体数值为建模近似），内部战斗空间仍为独立的扩张空间。宿傩的范围由施放位置到结界外壳的距离加外壳半径与0.1米表现裕量计算，只包围外壳，不将内部空间尺寸当成现实领域半径。HUD明确区分最大范围与结界集中模式。

持续5秒、每跳伤害、结界耐久40、外侧基础侵蚀14/秒、累计损失30%最大生命后的维持失败均为游戏参数。

封闭领域保留既有扩张内部空间与角色返回位置，同时记录施放时的现实外壳位置与尺度用于外侧侵蚀。本次未增加新的涩谷宿傩关卡，因此不把140米限制移植到其他阶段。未实现手动调整领域半径、结界条件反转、无量空处0.01秒先手或原著数次领域再展开的完整流程。通用场景并未模拟所有建筑被粉碎。

乙骨借体剧情参照原著三分钟结界争夺，游戏仍使用既有90秒（简单110秒）的章节计时与结局，计时为改编，不改成通用自由对战的外壳耐久机制。
