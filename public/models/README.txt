角色模型放置说明（占位自动替换）
====================================

把下面三个 glTF 模型文件放进本目录，游戏会自动加载并替换掉当前的几何体占位角色：

  gojo.glb       五条悟
  sukuna.glb     宿傩
  mahoraga.glb   魔虚罗

要求：
  - 格式：.glb（内嵌贴图），或 .gltf + 配套资源（需自行调整 models.js 中的路径）
  - 模型朝向：默认正面朝 +Z、头顶朝 +Y
  - 尺寸不限，代码会按包围盒自动缩放到约 1.6 个世界单位并居中

如果文件不存在，游戏会安全地回退到内置的几何体占位角色，不会报错。

自定义文件名 / 路径：编辑 src/three/models.js 里的 loadGltf() 中的 paths 映射。
