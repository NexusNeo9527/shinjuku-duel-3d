# 新宿决战 3D · Shinjuku Duel 3D

> 一个基于 **Three.js** 的第三人称立体咒术对战游戏。自由飞行、自动锁定、术式相杀、领域展开——在 3D 天空中决出胜负。

当前版本：**0.2.11**。主战场选择现在只有「剧情模式」与「自由战斗」；五条悟 VS 宿傩经典对决收纳在剧情模式中，保留原始模式的单人、双人和练习玩法。剧情章节列表可预先选择操控剧情方或对手方，进入难度页后仍可切换；练习模式也会按所选阵营进入，受剧情限制的章节会锁定角色。新宿 01「五条悟 VS 宿傩」仍按故事顺序接续鹿紫云章节。游戏还包括怀玉、涩谷、死灭回游与新宿篇。战场活动范围扩大到 144×144，新增多个差异化战场、领域视觉效果和完整启动预加载。主菜单提供剧情、自由战斗、游戏说明与设置；设置支持音量、键位重映射和触屏摇杆位置调整。

本次更新：木桩靶子新增敌人角色选择，覆盖全部22种角色与时期配置，支持同角色对练；选择后自动开启靶子并重置战斗，关闭再开启和击倒重生仍保留所选敌人。练习终端可直接切换全部22种可玩角色与时期配置，包括自由战斗角色及原有剧情练习角色；切换后重置战斗与技能冷却，保留练习选项。

伏魔御厨子通常以最大半径约 **200米** 展开，现实战场按1场景单位=1米计算，中心展开可覆盖当前144×144米战场及飞行高度；地图边界不等于领域边界，超过实际范围才停止必中。借五条之身的领域交锋中，宿傩主动缩小范围包围微型结界，结界内部战斗空间与现实外壳分别计算。伤害、持续时间与结界耐久为游戏改编。详见 [开放领域原著机制](docs/open-domain-canon.md)。

现有阶段技能已补齐并提供翻页操作：玩家1按 `2`，玩家2按反斜杠，触屏点击“换技能”。各页沿用五个术式键，冷却分别计算。简易领域按习得时期开放，操控阵营可正常切换；后期虎杖御厨子与领域留给对应新阶段。角色清单、原著依据与数值改编见 [各时期技能说明](docs/period-skills.md)。

五条悟 **VS** 宿傩。没有瞄准的负担，只有走位、时机与术式博弈。本游戏的制作思路来源某站up主：**艾薇慕姬卡科技**

## 游戏特色

- **全 3D 立体战场**：自由飞行、升降高度、空中缠斗，不再是平面弹幕。
- **自动锁定 · 无需瞄准**：攻击会自动飞向锁定目标，单屏视角自动对准目标；双人为左右分屏，**两侧各自显示血量、能量与技能冷却**。
- **术式相杀 / 术式突破**：飞行道具对撞时按等级判定——同级同归于尽，等级高者贯穿并削弱对方。
- **领域展开**：封闭领域捕获目标；伏魔御厨子以约200米的开放范围持续斩击。等强度领域重叠处必中抵消，开放领域可从外侧侵蚀封闭结界。
- **黑闪 · 反转术式 · 魔虚罗**：还原原作的关键机制（见下方[战斗机制](#战斗机制)）。
- **双主题界面**：五条悟「苍蓝」/ 宿傩「血咒」两套 UI 配色可随时切换。
- **背景音乐**：主菜单保持静音；进入五条篇后默认《雨爱》正常版，练习战默认司凤版，乙骨篇默认《心似烟火》DJ 版。顶栏 **♫** 可切换当前场景曲目，设置页可调节总音量。
- **移动端**：横屏、竖屏都能玩，无需旋转屏幕；触屏双拇指操控，并有独立的「切换目标」按钮。设置中的预览可拖动移动摇杆位置，双人触屏会自动镜像。
- **键位设置**：两个玩家的移动、术式与战斗按键都能在设置中重映射；配置保存在当前设备。

## 战斗机制

- **术式熔断**：领域自然结束或维持失败后，生得术式进入熔断，体术与已习得的反领域手段仍可使用。期间可用 `V` 近身攻击和 `F` 冲刺；成年五条与对应宿傩形态可按 `H` 扣除最大生命的 20% 强行恢复，本场领域随即锁定；普通身体反转恢复不等于恢复熔断术式。双人键盘由 P2 使用 `;` 近身、`'` 恢复。触屏有对应按钮。
- **剧情挑战**：怀玉、涩谷与新宿篇使用角色在对应时期的技能。新宿顺序为五条悟 VS 宿傩 → 鹿紫云 → 日车与虎杖 → 乙骨本体 → 五条之身。五条对宿傩沿用经典技能，作为游戏改编关卡；后续新宿战包含幻兽琥珀、电荷放电、神武解雷击免疫、诛伏赐死没收咒具及可闪避的处刑人之剑。所有关卡击败对手即可通关，玩家倒下则失败；普通攻击可以终结，四档难度依次增加敌人强度。原著依据及数值改编见 [新宿协战说明](docs/shinjuku-raid-canon.md)。
- **乙骨剧情战**：第一场使用咒力刀、里香、复制术式、真赝相爱及反转术式。`G` 切换咒言、天空操术·薄冰破、雅各布天梯、复制捌、G战杖未来视与德鲁夫式神轨迹，`E` 施放；触屏使用“切换复制”。借用五条身体的关卡使用体术、苍、需要站定准备的茈，以及一次狗卷录音支援；宿傩以领域展延和体术应对。开场自动领域对抗，结界计时结束后进入术式熔断并继续战斗，不直接判负。

- **术式相杀 / 术式突破**：两个飞行道具相遇时比较等级（power）。**同级**时双方术式同时湮灭；**等级不同**时高等级贯穿低等级，但会被削弱——伤害 ×0.58（最低 4）、击退 ×0.7、爆炸半径 ×0.82，且等级 −1。
- **奥义 / 领域充能**：茈、无量空处、开、伏魔御厨子**没有独立冷却**，只要对应的 **奥义 / 领域** 槽攒满即可释放（命中一次 +20 奥义 / +14 领域）。技能格直接显示充能进度，攒满即亮。
- **黑闪**：命中瞬间有 **18%** 概率触发，伤害 **×1.55**（双方共享此机制）。
- **领域对撞**：双方同时展开领域时触发对峙，按强度判定胜负。
- **无量空处**：信息必中使目标无法行动；接触施术者、已展开的反领域防御及领域对抗可抵消。
- **反转术式**：可用形态以独立技能主动恢复身体；经典电脑对战的困难 / 地狱另保留五条被动恢复，数值为游戏改编。
- **魔虚罗**：限时召唤，血量 / 速度 / 存活时长 / 伤害**随难度提升**（简单 55 血 → 地狱 140 血）。每次被同一术式命中会**适应**该术式并叠加减伤（每层 −18%，上限 55%）。友军火力对其无效。
- **连招（命中判定）**：在 **1.3 秒**内按顺序**命中**对手才触发强化伤害，而非按键即触发。

## 操作说明

> 攻击**无需瞄准**：左键/技能键会自动锁定并飞向目标。

### 键盘 · 玩家1（五条悟）

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动（可在设置里更改） |
| `左 Shift` | 疾跑 |
| **按住 `空格`** | 升空（按住持续上升） |
| `X` | 下降 |
| **左 `Alt`** | 切换锁定目标 |
| **鼠标左键** / `1` | 术式 1 |
| `Q` / `E` / `R` / `T` | 术式 2–5 |
| `G` / `H` / `V` / `F` | 切换复制术式 / 强行恢复 / 近身攻击 / 冲刺 |
| `C` | 简易领域（成年五条、新宿虎杖、涩谷未伤手东堂） |
| `2` | 切换技能页 |
| 滚轮 | 镜头缩放 |

| 按键 | 功能 |
| --- | --- |
| `I` `J` `K` `L` | 移动（可在设置里更改） |
| 右 `Shift` | 疾跑 |

| `U` / `O` / `P` / `[` / `]` | 术式 1–5 |
| `,` / `/` | 切换复制术式 / 切换锁定目标 |
| `;` / `'` / `B` | 近身攻击 / 强行恢复 / 冲刺 |
| `.` | 简易领域（选择已习得的时期形态时） |
| 反斜杠 | 切换技能页 |

### 触屏操作

- **左半屏**：虚拟摇杆控制移动
- **右半屏**：拖动转动视角
- **独立按钮**：升空 / 下降、技能键、疾跑、冲刺、**切换目标**
- **全屏**：顶栏的 ⛶ 按钮可进入全屏，横屏时能隐藏浏览器工具栏、腾出更多画面
- **技能翻页**：技能多于五项时显示“换技能”，双方触屏各自切换。
- **简易领域**：可用角色显示独立按钮，按钮上显示持续时间或冷却秒数。
- **屏幕方向**：不强制横屏。横屏为紧凑布局（顶栏压缩、控件贴合安全区），竖屏会把操作区集中到拇指够得到的位置，两种方向都能正常游玩。

## 简易领域

成年五条、新宿战前训练后的虎杖、涩谷未伤手东堂可以展开脚下的小范围光环，暂时抵消敌方领域的必中持续伤害与领域压制，争取恢复、移动或反击的时间。普通术式、近战仍可命中；简易领域受到领域侵蚀后会破碎，敌方领域继续存在。术式熔断期间仍可使用。

游戏数值：最长维持 5 秒、冷却 16 秒、稳定度 32；敌方领域每次必中消耗稳定度，强度越高侵蚀越快。练习模式的“无限术式”可免除冷却。高专五条、涩谷及死灭回游虎杖、乙骨本体和借五条之身不开放。涩谷东堂虽尝试展开，仍赶不上真人的0.2秒领域；伤手后不可再用。新宿虎杖支援会自动应对敌方领域。

原著依据：第 171 话对抵消必中与术式本体的区分，以及第 226 话五条在熔断期间展开简易领域、随后被伏魔御厨子压碎的场景。参考：[简易领域设定整理](https://jujutsu-kaisen.fandom.com/wiki/Simple_Domain)、[第 226 话整理](https://jujutsu-kaisen.fandom.com/wiki/Chapter_226)。以上数值为游戏平衡设计。

## 难度

| 难度 | 敌人耐久 | 魔虚罗 | 特点 |
| --- | --- | --- | --- |
| **简单** | 85 | 55 血 · 伤害 ×0.75 | 出招较慢 · 伤害较低 |
| **普通** | 100 | 72 血 · 伤害 ×1 | 预判移动 · 敌人输出 ×1 |
| **困难** | 115 | 100 血 · 伤害 ×1.3 | 敌人输出 ×1.1 · 五条被动恢复 |
| **地狱** | 130 | 140 血 · 伤害 ×1.6 | 敌人输出 ×1.2 · 原模式魔虚罗开场 |

难度决定敌人的耐久、瞄准精度、反应速度、伤害与机动，以及**魔虚罗的耐久 / 速度 / 存活时间 / 伤害**——不随时间变化。难度不再额外减免敌人的承伤；乙骨本体剧情的困难／地狱敌人耐久为110／120。以上均为游戏调校参数。

## 运行与构建

```bash
# 安装依赖
npm install

# 本地开发（http://localhost:5173）
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 预览构建结果
npm run preview
```
