## 游戏特色

- **全 3D 立体战场**：自由飞行、升降高度、空中缠斗，不再是平面弹幕。
- **自动锁定 · 无需瞄准**：攻击会自动飞向锁定目标，单屏视角自动对准目标，双人为左右分屏。
- **术式相杀 / 术式突破**：飞行道具对撞时按等级判定——同级同归于尽，等级高者贯穿并削弱对方。
- **领域展开**：无量空处与伏魔御厨子对撞，展开领域内持续压制、减速与伤害。
- **黑闪 · 反转术式 · 魔虚罗**：还原原作的关键机制（见下方[战斗机制](#战斗机制)）。
- **双主题界面**：五条悟「苍蓝」/ 宿傩「血咒」两套 UI 配色可随时切换。
- **触屏支持**：移动端双拇指操控（左摇杆移动、右半屏转视角、独立技能键）。

## 战斗机制

- **术式相杀 / 术式突破**：两个飞行道具相遇时比较等级（power）。**同级**时双方术式同时湮灭；**等级不同**时高等级贯穿低等级，但会被削弱——伤害 ×0.58（最低 4）、击退 ×0.7、爆炸半径 ×0.82，且等级 −1。
- **黑闪**：命中瞬间有 **18%** 概率触发，伤害 **×1.55**（双方共享此机制）。
- **领域对撞**：双方同时展开领域时触发对峙，按强度判定胜负。
- **无量空处**：命中后造成眩晕与减速，领域内持续掉血。
- **反转术式**：修罗 / 无间难度下，五条悟以 `/秒` 缓慢回复生命。
- **魔虚罗**：72 点生命、限时召唤，每次被同一术式命中会**适应**该术式并叠加减伤（每层 −18%，上限 55%）。友军火力对其无效。
- **连招（命中判定）**：在 **1.3 秒**内按顺序**命中**对手才触发强化伤害，而非按键即触发。

## 操作说明

> 攻击**无需瞄准**：左键/技能键会自动锁定并飞向目标。

### 键盘 · 玩家1（五条悟）

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 疾跑 |
| **长按 `空格`** | 升空（按住持续上升） |
| `Z` / `X` | 升空 / 下降 |
| **轻按 `空格`** | 切换锁定目标 |
| **鼠标左键** / `1` | 苍 |
| `Q` / `2` | 赫 |
| `E` / `3` | 茈 |
| `R` / `4` | 无量空处（领域） |
| `T` / `5` | 魔虚罗 |
| `F` | 冲刺（短暂无敌） |
| 滚轮 | 镜头缩放 |
| `Esc` | 暂停 |

### 键盘 · 玩家2（宿傩，双人模式）

| 按键 | 功能 |
| --- | --- |
| `I` `J` `K` `L` | 移动 |
| 右 `Shift` | 疾跑 |
| `N` / `M` | 升空 / 下降 |
| `U` | 解 |
| `O` | 捌 |
| `P` | 开 |
| `[` | 伏魔御厨子（领域） |
| `]` | 魔虚罗 |
| `B` | 冲刺 |

### 触屏操作

- **左半屏**：虚拟摇杆控制移动
- **右半屏**：拖动转动视角
- **独立按钮**：升空 / 下降、技能键、疾跑、冲刺、锁定

## 难度

| 难度 | 敌人耐久 | 特点 |
| --- | --- | --- |
| **轻松** | 85 | 出招较慢 · 伤害较低 |
| **标准** | 100 | 预判移动 · 减伤 |
| **修罗** | 125 | 魔虚罗 70 血入场 · 反转术式 |
| **无间** | 150 | 未削弱的宿傩 · 魔虚罗开场 |

难度决定敌人的耐久、瞄准精度、反应速度、伤害、减伤与机动——**不随时间变化**。

## 运行与构建

```bash
# 安装依赖
npm install

# 本地开发（http://localhost:5173）
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 预览构建结果
npm run preview
```

## 技术栈

- [Three.js](https://threejs.org/) — 场景、模型、粒子与后处理
- [Vite](https://vitejs.dev/) — 开发服务器与打包
- 原生 ES Modules + Canvas UI，无前端框架

## 项目结构

```
.
├── index.html              # 页面骨架与 UI 结构
├── public/
│   └── assets/             # 领域 / 术式立绘等图片资源

    ├── Game3D.js           # 核心战斗逻辑（弹道、相杀、领域、AI）

    ├── audio.js            # 音效引擎
    ├── style.css           # 主题与界面样式
    └── three/
        ├── Renderer3D.js   # 相机、分屏、锁定、特效
        ├── models.js       # 程序化角色模型
        ├── Particles.js    # 粒子系统
        └── Post.js         # 后处理
```
